# Programação de Tarefas (Scheduling)

Esta pasta contém implementações para a solução do problema de programação de tarefas em diferentes ambientes de máquinas, organizados, por exemplo, da seguinte forma:

- Máquina única
- Máquinas paralelas
- Flow shop
- Job shop

Dentro de cada ambiente, os arquivos estão separados, por exemplo, em:

- Modelos exatos
- Heurísticas
- Gerador de instâncias
